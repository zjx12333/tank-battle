# 坦克大战 · Tank Battle

一个纯前端的 HTML5 Canvas 坦克大战（Battle City 风格）。**零依赖、零构建**，双击 `index.html` 就能玩。

## 玩法

你是左下角的黄色坦克，任务是**守住底部的基地（老鹰）**，消灭全部来袭敌军。

- **砖墙**可以被炮弹炸开，**钢墙**只有满级火力才能击穿
- 基地周围有砖墙护盾，被打穿就输了
- 敌军有 4 种：常规、快速、强火力、装甲（3 血）

### 操作

| 动作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或 方向键 |
| 发射 | `空格` 或 `J` |
| 暂停 | `P` / `Esc` |
| 静音 | `M` |

手机上会自动显示方向键和发射按钮。

### 道具

击毁**闪烁的敌军坦克**会掉落道具：

| 图标 | 名称 | 效果 |
| --- | --- | --- |
| ★ | 火力提升 | 提升弹速 / 弹量，满级可击穿钢墙（最高 4 级） |
| ♥ | 增加生命 | 生命 +1 |
| ◉ | 全屏轰炸 | 立即消灭场上所有敌军 |
| ⛨ | 无敌护盾 | 12 秒无敌 |
| ◷ | 冻结敌军 | 8 秒内敌军无法行动 |
| ⛏ | 基地铁壁 | 18 秒内基地砖墙变为钢墙 |

### 关卡

1. **丛林前哨** — 12 辆敌军，场上最多 4 辆
2. **钢铁防线** — 16 辆敌军，场上最多 5 辆
3. **死亡峡谷** — 20 辆敌军，场上最多 6 辆

## 本地运行

不需要安装任何东西，也不需要服务器：

```bash
# 直接双击 index.html 即可
# 或者起一个本地服务（可选）
python -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 部署到 GitHub Pages

1. 把仓库推到 GitHub
2. 进入仓库 **Settings → Pages**
3. **Source** 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
4. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

不需要任何构建步骤 —— 这是个纯静态站点。

## 技术要点

- **渲染**：Canvas 2D，所有图形都是代码绘制的矢量图形，没有美术资源
- **音效**：`js/audio.js` 用振荡器和噪声实时合成，同样零资源文件
- **物理**：固定步长（1/120s）更新，防止掉帧时炮弹穿墙
- **移动手感**：转向时把垂直方向对齐到格中心，避免卡墙角
- **地图**：13×13 字符画数组，`B`=砖 `S`=钢 `W`=水 `T`=树 `E`=基地

想加关卡？在 `js/game.js` 的 `LEVELS` 数组里照着写一个 13×13 的字符画就行。
